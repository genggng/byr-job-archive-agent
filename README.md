# 北邮人论坛招聘信息归档与求职助手

这是一个实用的北邮人论坛招聘信息整理工具。

它通过论坛官方 Telnet `guest` 访客入口，只读获取以下就业版面的帖子：

- `JobInfo`：招聘信息专版
- `Job`：毕业生找工作
- `Jump`：跳槽就业

不需要论坛账号、密码或 Cookie，也不会发帖、回帖或修改论坛内容。

## 提供什么

- 获取最近若干月的校招、社招、实习、内推和就业讨论；
- 自动保存原帖，重复运行时只更新新增或发生变化的内容；
- 生成可筛选、排序的 Excel 招聘信息表；
- 支持中断后继续运行，不会因为网络失败丢失已有数据；
- 提供 Agent Skill，让 Agent 可以查找岗位、核对原帖并给出就业建议。

## 使用方式一：生成 Excel 招聘信息表

### 1. 安装依赖

需要 Python 3.10 或更高版本。

```bash
python3 -m pip install -r requirements.txt
```

### 2. 获取招聘信息

```bash
python3 byr_job_archive.py
```

### 3. 选择时间范围

`--days` 用于指定首次获取最近多少天的帖子。例如：

```bash
# 最近 3 个月
python3 byr_job_archive.py --days 90

# 最近 6 个月
python3 byr_job_archive.py --days 180

# 最近 12 个月
python3 byr_job_archive.py --days 365
```

不指定时默认获取最近 365 天。

### 4. 查看结果

运行完成后，结果保存在：

```text
北邮人论坛近一年归档/
├── JobInfo-招聘信息专版/
├── Job-毕业生找工作/
├── Jump-跳槽就业/
└── 北邮人论坛招聘索引.xlsx
```

Excel 中可以按公司、招聘类型、岗位类别、地点、毕业届别和发布时间等字段筛选。

再次运行相同命令即可增量更新。已经保存且没有变化的帖子不会重复写入。

只想重新生成 Excel、不访问论坛时：

```bash
python3 byr_job_archive.py --rebuild-excel
```

## 使用方式二：安装 Agent Skill

请从本仓库安装 `byr-job-advisor` Skill，让 Agent 具备获取、检索北邮人论坛招聘信息并提供就业建议的能力。

## 常见问题

### 访客席位已满

稍等几分钟后重新运行。已经归档的帖子不会重复下载。

### 运行中断

重新执行相同命令即可继续，已经完成的内容会保留。

### 自动分类是否完全准确

公司、岗位、地点和招聘类型等字段用于快速筛选，可能存在遗漏或误判。投递前请查看对应原帖正文。
